Opting into paper or live


By default the plugin is locked to research. To move to paper or live, take these steps in order:


    

  1. Edit /a0/usr/plugins/vibe_trading/config.json (or default_config.yaml): set risk_tier to paper or live. Or set env VIBE_TRADING_RISK_TIER=paper before starting Agent Zero.
    2. 

  2. Keep require_explicit_confirmation: true so the gate blocks any live order until you say OK per action.
    3. 

  3. Restart Agent Zero so hooks.py re-registers the MCP server with the new tier.
    4. 

  4. Open the Connectors tab on the dashboard and verify the brokers you want to enable are listed as reachable (use check_broker below to deep-check one).
    5. 

  5. Test in paper first. Promote to live only after you have run the strategy in paper for a meaningful period.
    6.
